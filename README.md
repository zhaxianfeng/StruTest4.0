# StruTest4.0

## Overview

StruTest4.0 is an Excel-based tool developed for the quantitative quality assessment of structural orientation datasets in digital geological mapping. The software automatically validates planar and linear structural measurements based on their geometric relationships and calculates orientation errors for rapid quality evaluation.

The program is designed to improve the efficiency and reliability of structural data quality control and can be applied to geological mapping, structural geology investigations, and other structural dataset analyses. It can be a complementary approach to the stereographic projection.

---

## Main Features

- Automatic validation of planar structural measurements.
- Automatic validation of linear structural measurements.
- Quantitative calculation of orientation errors.
- Automatic identification of incorrect measurements.
- Rapid quality assessment of large structural datasets.
- No programming environment required; runs directly in Microsoft Excel.

## Getting Started

1. Download the repository.
2. Open **StruTest4.0.xlsx** using Microsoft Excel.
3. Import structural orientation data into the corresponding worksheets.
4. The software automatically performs quality assessment and calculates orientation errors.
5. Review the generated assessment results.

---

## Input Data

The software accepts structural orientation data in a numeric format, including:

### Planar measurements (worksheet: **Test of Plane**)

Input the following parameters:

- Strike
- Dip direction
- Dip angle


### Linear measurements (worksheet: **Test of Linear**)

Input the following parameters:

- Plunge direction (trend)
- Plunge angle
- Corresponding planar orientation

Example datasets are provided in this repository.

---

## Output

StruTest4.0 automatically generates the following outputs.

### Planar measurements (worksheet: **Test of Plane**)

- Validation results for planar measurements
- Comments for each input measurement
- Classification of measurements as **ACCEPTED** or **WRONG DATA** (incorrect measurements are highlighted in red)
- Total number of input measurements
- Number and percentage of **ACCEPTED** measurements
- Overall quality evaluation of the dataset

### Linear measurements (worksheet: **Test of Linear**)

- Validation results for linear measurements
- Plunge angle and plunge direction errors
- Comments for each input measurement
- Classification of measurements as **ACCEPTED**, **ERROR**, or **WRONG DATA** (incorrect measurements are highlighted in red)
- Total number of input measurements
- Number and percentage of **WRONG DATA**
- Number and percentage of **ACCEPTED** measurements
- Overall quality evaluation of the dataset

**Note**

- **WRONG DATA** indicates measurements that violate the required geometric relationships and should be corrected or discarded.
- **ERROR** indicates measurements that satisfy the geometric relationships but exceed the user-defined acceptable error threshold.
